🚀 نسخة محدثة v2 (معتمدة للتنفيذ)

Royal Bank — Implementation Plan

وثيقة التصميم الهندسي والتنفيذي الكامل لمنصة بنك الأسئلة والمكتبة الطبية السريرية (MRCP, MRCOG, MRCS, PLAB) المبنية بـ Next.js 15 و Supabase و Cloudflare R2 بواجهة مطابقة لـ PassMedicine.

📌 1. أبرز التعديلات في النسخة المحدثة (v2)

تم اعتماد وتنفيذ جميع متطلبات التحديث المتفق عليها:

# البند التفاصيل الفنية
1 ☁️ Cloudflare R2 تخزين ميديا وصور الأسئلة على Cloudflare R2 CDN لتوفير سرعة فائقة وتقليل استهلاك الباندويث بدون قيود Supabase Storage.
2 🧱 نظام البلوكات (Block System) الحساب المجاني (Free Trial) يمنح بلوك تدريبي واحد (بحد أقصى 70 سؤال)، مع إمكانية تحكم الإدارة بعدد البلوكات لكل مستخدم.
3 👥 لوحة الدعم الفني (Support Desk) واجهة مخصصة ومنفصلة لفريق الدعم لتفعيل وترقية الاشتراكات السنوية والشهرية فورياً عبر البحث بالإيميل الوارد من Telegram.
4 🗄️ تنظيف وهيكلة الـ Schema دمج subject و system في عمود category موحد، إزالة الأعمدة المكررة، والاحتفاظ بـ notes_id و concepts_json.
5 📚 مكتبة الكتب السريرية المنفصلة إنشاء جدول library_articles يضم 650+ مقالاً سريرياً مربوطة بالأسئلة عبر notes_id.
6 💡 مفاهيم الأسئلة المحفوظة (Saved Concepts) ميزة تتيح للطلاب حفظ وتصنيف المفاهيم السريرية عبر أزرار Important / Less Important مع صفحة مراجعة بالقائمة الجانبية.
7 🎨 واجهة PassMedicine مطابقة محاكاة دقيقة لشاشات الأسئلة، الجداول، أشرطة النسب المئوية، محرر الملاحظات، واللوحات الجانبية.
8 🚫 كود حقيقي بدون Mocks بناء جميع الوظائف برمجياً بكود جاهز للإنتاج (Production-grade code).

⚡ 2. حزمة التقنيات (Tech Stack)

التقنية الدور في المنصة
Next.js 15 (App Router) إطار العمل الشامل (SSR + React Server Components + Server Actions).
Supabase (PostgreSQL) قاعدة البيانات العلائقية، نظام المصادقة (Auth)، والتحكم بالصلاحيات (RLS).
Cloudflare R2 تخزين وتوزيع الميديا السريرية (صور الحالات، تخطيط القلب ECG، الأشعة السينية).
Tailwind CSS v4 & shadcn/ui بناء الواجهات الطبية والتصميم المتجاوب.
TanStack Query (React Query) إدارة الكاش ومزامنة البيانات في المتصفح.
Zustand إدارة حالة جلسة الامتحان (Active Question, Timer, Answers, Highlights, Strike-out).
DOMPurify تنقية نصوص وشروحات الأسئلة السريرية للحماية من ثغرات XSS.
next-themes دعم التبديل السلس بين الوضع الليلي والنهاري (Dark / Light Mode).
Vercel الاستضافة السحابية مع التوزيع العالمي عبر الـ Edge Network.

🗄️ 3. هيكل قاعدة البيانات (Database Schema)

1. جدول الأسئلة (public.questions)

العمود النوع الوصف
idBIGSERIAL PKالمعرف الأساسي للسؤال.
main_idBIGINT UNIQUEالمعرف الأصلي لتفادي التكرار (Deduplication).
text_htmlTEXTنص الحالة السريرية والسؤال مع الجداول والصور.
explanation_htmlTEXTالشرح الطبي المفصل والشامل للحالة.
categoryTEXTالتخصص الطبي (Cardiology, Neurology, etc.).
topicTEXTالموضوع السريري الدقيق (Sub-category).
conceptTEXTالمفهوم الأساسي المختبر بالسؤال.
concept_idTEXTمعرف المفهوم للربط الإحصائي.
notes_idTEXTالمعرف الرابط بمقال الـ Textbook في library_articles.
difficultyTEXTمستوى الصعوبة (1, 2, 3).
pm_question_idTEXTالمعرف المرجعي الأصلي.
concepts_jsonTEXTبيانات المفاهيم المرجعية للبحث والتحليل المستقبلي.
created_atTIMESTAMPTZتاريخ الإضافة.

2. جدول الاختيارات (public.options)

العمود النوع الوصف
idBIGSERIAL PKمعرف الاختيار.
question_idBIGINT FKالربط بجدول الأسئلة (questions.id).
text_htmlTEXTنص الاختيار الطبي.
is_correctBOOLEANهل هذا الاختيار هو الإجابة الصحيحة؟
option_orderINTترتيب عرض الاختيار (A, B, C, D, E).
percentageREALنسبة اختيار الزملاء (Peer Statistics) لعرض شريط النسبة.

3. جدول فصول ومقالات الكتب (public.library_articles)

العمود النوع الوصف
idTEXT PKمعرف المقال السريري (مثل "1_372").
nameTEXTعنوان الفصل الطبي.
categoryTEXTالتخصص الطبي التابع له.
content_htmlTEXTالمحتوى الطبي الشامل للفصل.
sourceTEXTالمصدر الأصلي للمقال.
created_atTIMESTAMPTZتاريخ الإضافة.

🎨 4. تجربة المستخدم وواجهات PassMedicine

أقسام القائمة الجانبية (Sidebar Navigation)

  • QUESTIONS: Question bank, Fixed sets & timed tests, Mock exams, Review questions, Performance, Comment threads.
  • TEXTBOOKS: High-yield textbook, Extended textbook.
  • KNOWLEDGE TUTOR: Knowledge tutor, Review facts.
  • CUSTOM REVISION: Revision sets.
  • CONCEPTS: All concepts, Top 100 concepts, 💡 Saved Concepts.

مكونات واجهة الامتحان التفاعلية

  • الشريط العلوي: عداد الأسئلة (Question X of Y)، زر الإلهاء والخروج، علامة المراجعة (Flag 🚩)، والمؤقت الزمني.
  • الخيارات الذكية: أشرطة بيانية تظهر نسب اختيار الزملاء بعد الإجابة (أخضر للصحيح، أحمر للخطأ) مع أداة الاستبعاد (Strike-out).
  • لافتة المفهوم السريري (Green Concept Banner): ملخص القاعدة الطبية مع أزرار التقييم والحفظ (Important / Less Important).
  • شريط الملاحظات السريرية: محرر نصوص غني أسفل كل سؤال يتيح حفظ ملاحظات الطالب الخاصة تلقائياً.
  • اللوحة الجانبية الذكية: تضم روابط الكتاب المباشرة للموضوع، خريطة الأعراض (Content Map)، ومؤشر مقارنة الدرجات (Benchmark Score).

👥 5. لوحات الإدارة والدعم الفني

1. لوحة الدعم الفني السريع (/support)

مخصصة لموظفي الدعم لتفعيل الاشتراكات اليدوية الواردة عبر Telegram:

  • البحث الفوري عن حساب الطالب عبر البريد الإلكتروني.
  • تحديد نوع الاشتراك: تخصص واحد (Individual) أو وصول شامل (Full Access).
  • تحديد المدة الزمنية: (1، 3، 6، 12 شهراً أو Lifetime).
  • تفعيل فوري بضغطة زر واحدة دون الحاجة للدخول إلى إعدادات السيرفر.

2. لوحة الإدارة الشاملة (/admin)

  • متابعة المقاييس: أعداد الطلاب الجدد، الاشتراكات النشطة، ومعدل التحويل (Conversion Rate).
  • إدارة المستخدمين والأجهزة: رصد عناوين الـ IP وعدد الأجهزة المتصلة لكل حساب لمنع مشاركة الحسابات.
  • جدار الحماية والأمان: حظر عناوين الـ IP المسيئة بنقرة واحدة مع سجل كامل للأسباب.

🛡️ 7. الحماية ومكافحة مشاركة الحسابات

  • بصمة الجهاز (Device Fingerprinting): تسجيل عنوان الـ IP ونوع المتصفح ونظام التشغيل، مع تنبيه الإدارة عند تجاوز الحد المسموح (أكثر من جهازين).
  • الحظر الذكي: رصد تسجيل الدخول من أكثر من 3 عناوين IP مختلفة في غضون 24 ساعة وتعليق الحساب مؤقتاً.
  • حماية الجلسات (JWT Tokens): استخدام Supabase Auth لإلغاء الجلسات النشطة فورياً عند تغيير كلمة المرور أو الحظر.

📅 8. مراحل التنفيذ المعتمدة (Implementation Phases)

Phase 1: الأساسات وقاعدة البيانات (تم الإنجاز بنجاح ✅)

تم إعداد مشروع Next.js 15 مع Tailwind CSS v4 و Dark Mode و TypeScript.
تم كتابة وتجهيز ملفات الـ SQL Migrations و RLS Functions لقاعدة البيانات.
تم تطوير محرك استخراج ومعالجة 5,444 سؤال و 650 مقال textbook.
تم بناء واجهة الأسئلة وحساب النسب ولوحات التحكم (Admin & Support).
تم التحقق من عمل الـ Build بنسبة 100% بدون أي أخطاء برمجية.

Phase 2: استكمال الخصائص المتقدمة والربط السحابي

قيد التنفيذ ربط قاعدة بيانات Supabase الحية وتشغيل استيراد البيانات الشامل.
قيد التنفيذ رفع مجلد الميديا السريرية إلى Cloudflare R2 Bucket.
قيد التنفيذ بناء شاشة الـ Performance والخريطة الحرارية (Heatmap).
قيد التنفيذ إعداد شاشة الامتحانات التجريبية (Mock Exams) ومراجعة الأسئلة الخاطئة.
