# Previous Sessions Rules

Previous Sessions is part of the completed core. It must show user-owned sessions only, distinguish active/incomplete from completed, resume the same locked set for incomplete sessions, and delete only the owner's session.

Deleting an unfinished session deletes that session and all of its session-scoped answers and locked questions. Its questions therefore return to New when no separate surviving answer or lock exists from another session. Deleting a session never refunds a consumed free-trial block.
