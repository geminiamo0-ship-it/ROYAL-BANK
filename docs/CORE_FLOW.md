# Completed Core Smoke Flow

1. Register/login active student.
2. View pathway/bank catalog; premium banks render locked without exposing question content.
3. Configure Question Bank filters/count.
4. Start allowed exam block; lock <=70 questions.
5. Answer in Standard/Tutor and verify final-on-submit.
6. Answer/change in Timed and verify editable until End Block.
7. Leave unfinished session; unanswered questions become Suspended and leave New.
8. Resume and receive identical locked set.
9. Delete unfinished session; unanswered locks return to New; trial quota is not refunded.
10. End Block; score derives from full locked block.
11. Previous Sessions reflects correct completion state.
12. Later Correct answer moves previously Incorrect question to Correct.
13. Flag persists until manual unflag.
